# Calendar view

The **Calendar** tab (sidebar, or the **Calendar** palette command) shows
a month grid for the journal. Weeks start on Monday.

- A day is highlighted when its journal has entries (at least one
  non-blank block). An empty journal — created but never written to —
  doesn't highlight.
- Clicking a day opens that journal in a tab (the calendar stays open).
  If the journal doesn't exist yet, it is created first, exactly like
  today's journal.
- `<` and `>` move month by month (across year ends); **Today** jumps
  back to the current month.

Journals are date-named pages (`YYYY-MM-DD`, files in `journals/`), so
the calendar needs no format of its own: anything it shows is already in
the vault, and anything it creates is an ordinary journal page.
